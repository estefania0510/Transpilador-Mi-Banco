      Ayuda y soporte

      Encuentra información para utilizar Mi Banco.

      ¿Cómo podemos ayudarte?

      Consulta algunas indicaciones para utilizar las opciones de tu cuenta.

      ¿Cómo consultar mi saldo?

      Ingresa a Inicio y encontrarás el saldo disponible de tu cuenta. También puedes actualizarlo con el botón correspondiente.

      ¿Cómo realizar una consignación?

      En Inicio, selecciona la opción Consignar, ingresa el valor y confirma la operación.

      ¿Cómo retirar dinero?

      Selecciona Retirar, escribe el monto que deseas retirar y confirma la operación.

      ¿Cómo transferir dinero?

      Selecciona Transferir, ingresa el número de cuenta de destino, el monto y confirma la transferencia.

      ¿Dónde puedo consultar mis movimientos?

      Entra a Movimientos para consultar tu historial. Puedes filtrar por tipo de operación y fechas.

      ¿Cómo cambiar mi contraseña?

      Ingresa a Seguridad, escribe tu contraseña actual y registra una nueva.

      ¿Necesitas más ayuda?

      Si tienes inconvenientes al utilizar la aplicación, comunícate con el equipo de soporte.
